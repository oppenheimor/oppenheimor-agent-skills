# 红领巾黑猫 IP

## 身份锚点

以 `../assets/character-reference.png` 为准。每次生成都加载并传入该图，不仅依赖文字描述。以下是可观察特征，不给角色虚构姓名、品牌背景或身世。

## 固定外形

- 黑色至炭黑色短毛猫，大圆头、饱满脸颊，耳侧少量毛簇。
- 两只三角猫耳，耳内金黄色。
- 很大的金黄色眼睛，黑色大瞳孔与小白色高光；不是两颗白点眼，也不是纯黑眼珠。
- 小巧的珊瑚红色近三角鼻，简洁黑色弧线嘴。
- 红色三角领巾，胸前有三角垂片，侧边有打结和两片飘带。参考图结位于画面右侧；换视角时随身体合理转动，不随意消失。
- 圆润紧凑的黑色身体，短而饱满的四肢、圆猫爪、粗而弯曲的尾巴。
- 保持参考图的大头短身比例；可以简化毛发和明暗，不能改成长腿人形或细线四肢。

## 可变内容

坐姿、站立、行走、侧面与三分之四视角均可。表情可认真、困惑、专注或轻松，但保持原有五官。可用前爪拟人化操作工具，不画人手。默认不增加衣服，确有任务需要时允许不遮挡领巾的小道具。

参考图的米白背景、坐姿和举爪并非身份特征；正文插图使用纯白底，不把参考图当贴纸直接塞进场景。

## 角色职责

每张默认出现黑猫，让它搬运、分拣、拉绳、修补、称重、推门、接住、记录或操作机器。幽默来自猫认真处理的不寻常任务，而不是扭曲猫的身体。

例如表达筛选时，让猫操作漏斗或筛网，不让它变成漏斗；表达信息汇聚时，让它整理线团，不把尾巴变成管道。

## 禁止漂移

- 不使用原项目的白点眼、黑豆/黑盒身体、细腿怪物。
- 不改为无领巾黑猫、白肚皮猫、其他毛色或其他物种。
- 不移除金黄眼部、耳内、红鼻子和红领巾等识别特征。
- 不加真人手、额外肢体、额外尾巴、夸张肌肉或复杂服装。
- 不以“不要可爱”为由去掉圆润轮廓和眼睛高光。
- 不仅在角落放一个与概念无关的猫头像。

## 判断

先与参考图比较：脱离场景仍应认得是同一只猫。再检查动作：去掉猫后核心动作若完全不变，说明它只是装饰，需要重新设计参与方式。
