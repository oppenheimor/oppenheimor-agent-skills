# 构图与原创隐喻

每张只选一种主要结构，猫的动作参与解释，不站在旁边充当装饰。

| 结构 | 适合内容 | 画法 |
| --- | --- | --- |
| 流程 | 输入、处理、输出 | 猫操作一个装置，少量物件表达输入输出 |
| 系统局部 | 来源、过滤、存储 | 只画 3–5 个核心模块，猫参与关键步骤 |
| 前后对比 | 混乱到有序、手动到自动 | 两个状态，一条轻量连接，保持同一角色 |
| 角色状态 | 信息焦虑、卡住、跑起来 | 2–4 个小场景，各配一句短标注 |
| 概念隐喻 | 工作流、知识管理、自动化 | 一个低科技怪物件加猫的具体操作 |
| 方法分层 | 层级、能力栈 | 猫搬盒子或搭台阶，避免正式金字塔 |
| 路线 | 学习、交付、承接 | 弯曲路径与少量节点，猫正在移动或修路 |
| 小漫画 | 失败到成功、吐槽 | 2–4 格，一个动作一格，不堆大段对白 |

## 发明当前文章自己的隐喻

1. 把抽象概念变成物理动作：卡住、漏掉、分拣、沉淀、开门、折叠、拆包、回流。
2. 用一个低科技物件承载结构：纸箱、抽屉、筛网、秤、邮筒、梯子、水管、线团、转盘、晾衣绳。
3. 让黑猫亲自完成关键动作：推、拉、接、修、称、守、标记、回收。

一张只选 1–2 个主物件。猫保持猫的身体，不能变成漏斗、黑盒、机器或洞口；让它操作这些物件。表情可变化，但眼睛、耳内、鼻子、领巾和圆润比例保持一致。

## 避免复刻

身份参考不等于构图模板。不要每张都画成参考图的坐姿举爪，也不要每个主题都套同一条传送带。系列图保持角色与视觉密度一致，同时变换动作、视角和隐喻。

只有用户明确要求复刻给定构图时才沿用它。即使改旧图，也以当前角色锚点为准，不继承旧角色的外形。
