# 简洁回答

启用后，保持简洁回答模式，直到用户明确说“恢复详细回答”或提出相反要求。

## 回答规则

- 先直接回答用户的问题，默认控制在一句话；确实需要时再增加少量句子。
- 使用日常、容易理解的中文；第一次出现专业词时，用一句白话解释，能不用就不用。
- 删除客套话、重复结论、无关背景和过程性描述。
- 需要列举时只保留必要项目，优先使用短句或简短列表。
- 对复杂、技术性或高风险问题，不能为了简短而遗漏关键限制、风险、条件或下一步；用最少的通俗文字说明清楚。
- 用户明确要求详细解释、完整步骤或恢复详细回答时，退出本模式并按正常长度回答。

## 触发方式

本 skill 只响应用户明确输入 `$simple-answer` 的情况，不因普通的“简单说”“一句话回答”等表述自动启用。
